Emerald Online 3DS is a clean-room homebrew framework that adds online presence to your own legally obtained Pokémon Emerald (US) cartridge dump running on Nintendo 3DS.

Features:
- Same-map trainer overlays with smooth interpolation, facing frames, and emote bubbles
- Map-local and global chat
- Online user roster with roles
- Browser-paired community forums and opt-in leaderboards
- Interactive quest log with NPCs and resource nodes
- Friends, guilds, and titles
- In-app updater and FBI-installable CIA

The ROM and save stay on your SD card; the app never ships with copyrighted game data. The public server code is open source and the game endpoint can be changed via online.cfg.
