  <h2 dir="auto">beta 1.1 (2026-11-16)</h2>

  <p dir="auto">It''s been some time since Beta 1.0 released, and this update aims
  to polish off any rough edges the previous release still had. It also marks the
  arrival of content and modes that were not present in the original Crash Team Racing.
  This content aims to be seamlessly integrated into the game.</p>

  <h3 dir="auto">New Content</h3>

  <ul dir="auto">

  <li><strong>Playable Nitros Oxide</strong>. Unlocked with a cheat code (ROSWELL),
  or by beating all his Time Trial ghosts.</li>

  <li><strong>EXPERIMENTAL: Boots and plays on Old 3DS.</strong> If you''re playing
  on an Old 3DS, I recommend installing the .cia. This lets us keep more of the game''s
  audio in memory, which reduces hitches.</li>

  <li>On Old 3DS, the left side of the touch screen acts as L2, and the right side
  acts as R2.</li>

  <li>Your <strong>best time</strong> on every track is <strong>automatically saved
  as a ghost</strong>. This ghost is loaded automatically on future attempts.</li>

  <li><strong>CTR Challenge</strong> and <strong>Relic Race</strong> can be chosen
  from Arcade menu.</li>

  <li>Added <strong>extra difficulties</strong> to Arcade mode.</li>

  <li>Arcade Mode Cup progression: "Hard" is unlocked right away. Beat all cups on
  Hard to unlock Super Hard.</li>

  <li>Beat all cups on Super Hard for a "legit" <strong>Penta Penguin unlock,</strong>
  and to unlock Ultra Hard.</li>

  <li>Beat all cups on Ultra Hard to unlock <strong>Mirror Mode</strong> (toggled
  from the main menu.)</li>

  <li><strong>Random CPUs</strong>: In Arcade mode, CPU characters will be chosen
  randomly from unlocked characters; in Adventure mode, boss characters can join normal
  races after you''ve defeated them.</li>

  <li>Added <strong>PAL languages</strong> (English, French, German, Italian, Spanish,
  and Dutch.) Existing and new content should be fully translated.</li>

  <li>Support for <strong>PAL voices</strong> (Requires your own PAL disc image; see
  README.) Thanks to <a class="user-mention notranslate" data-hovercard-type="user"
  data-hovercard-url="/users/LopezTutoriales/hovercard" data-octo-click="hovercard-link-click"
  data-octo-dimensions="link_type:self" href="https://github.com/LopezTutoriales">@LopezTutoriales</a></li>

  <li>Easter egg: <strong>Retro-Fueled mode</strong>. Toggle with the existing Super
  Turbo Pads cheat code (ARROW). Look up the Retro-Fueled mod for more information
  on how this mode works.</li>

  </ul>

CTR 3D is a Nintendo 3DS port of the PS1 game CTR: Crash Team Racing. It's built on top of ctr-native, a PC port based on the decompilation work done by the community. It adds everything you'd expect in a 3DS port: a minimap on the bottom screen, widescreen compatibility, stereoscopic 3D effect. Runs at a locked 30fps on New 3DS. Very playable on older 3DS models too.

Adds a playable Nitros Oxide, extra difficulties, and a few easter eggs, but gameplay remains faithful to the original.

Supports French, German, Dutch, Spanish, and Italian.
