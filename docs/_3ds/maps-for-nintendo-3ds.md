Explore the world on your Nintendo 3DS! Maps for Nintendo 3DS is an open-source mapping application featuring real street panoramas, a 3D globe, terrain exploration, GPS navigation, offline maps, and StreetGuess — a GeoGuessr-style geography game.

**Street View Explorer:**
- Explore real 360-degree street panoramas.
- Navigate between connected viewpoints.
- Supports Panoramax, Mapillary, KartaView, and experimental Google/Bing integrations.
- Gyroscope controls on New 3DS systems.
- Progressive imagery loading and higher-resolution detail on supported providers.

**3D Exploration:**
- Interactive, rotatable Earth globe with NASA imagery.
- Live 3D terrain using elevation data.
- 3D buildings using available OpenStreetMap data.
- Stereoscopic 3D support on compatible systems.

**StreetGuess — Geography Gaming:**
- GeoGuessr-style location guessing using street imagery.
- Classic World, USA, and Europe modes.
- Daily challenges and shareable friend challenges.
- Local pass-and-play multiplayer for 2–4 players.
- Country Streak, Mystery Expeditions, and Surprise Me.
- Moving, No Move, and NMPZ gameplay options.
- 32 curated panoramas across 21 countries.
- Timers, difficulty settings, distance scoring, and saved records.

**Maps and Navigation:**
- Interactive OpenStreetMap and satellite maps.
- Place search, favorites, and route planning.
- GPS tracking through a connected phone.
- Route progress, estimated arrival times, and automatic rerouting.
- Offline map caching and region downloads from supported sources.

**Customization:**
- Customizable button mappings and control profiles.
- Adjustable text sizes, contrast, and gyro settings.
- Improved interface and map loading performance.

**Installation:**
Download the CIA or 3DSX from GitHub Releases, or install through Universal-Updater. Online features require Wi-Fi and available provider coverage. Some imagery integrations are experimental, and physical-console testing of newer features is ongoing.
