A native Nintendo 3DS homebrew client for the live chat at [darksec.uk/chat](https://darksec.uk/chat).

The top screen shows the live message log; the bottom screen is a touch terminal keyboard for sending messages. Fully native 3DS controls with scroll, handle entry and a persistent connection.

* Live log on the top screen
* Touch keyboard terminal on the bottom screen
* Scroll with UP / DOWN, handle with SELECT
* Auto-reconnect
