A BBS terminal for the Nintendo 3DS that renders stereoscopic 3D scenes,
streamed audio and sixel graphics driven by the BBS itself, while remaining
a faithful ANSI-BBS terminal.

Identifies as CTerm 1.332, so Synchronet terminal autodetect and existing
SyncTERM-aware door code work unmodified. Telnet, rlogin and SSH with
per-board stored credentials and autologin. Truecolor, iCE colors, CP437,
scroll regions, mouse reporting, and selectable terminal geometry from
80x25 up to 132x60. Touch keyboard on the bottom screen, or mirror the
terminal across both.
