# talk with okelote!
this is my first game, made on löve2d, for nintendo 3ds

# installation (automatic)
0. homebrew ur 3ds! this can be done by using guides on [3ds.hacks.guides](https://3ds.hacks.guide/)
1. go to universal updater and download this game from there

# installation (manual)
0. homebrew ur 3ds! this can be done by using guides on [3ds.hacks.guides](https://3ds.hacks.guide/)
1. get a .3dsx file from releases/universal database (or build it)
2. put ur console's sd card intro ur pc
3. now, move that .3dsx file intro 3ds folder on ur sd card
4. put sd card back intro ur console
5. go to homebrew launcher and run the game! finally

# how to build
1. download zip archive of this repository
2. go to [online bundler](https://bundler.nawiasdev.eu/)
3. upload zip archive
4. download compiled bundle, inside it will be a .3dsx file with a game!
